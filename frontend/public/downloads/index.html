02 · 在服务器启动，保持回环监听

webcompare serve --host 127.0.0.1 --port 7865

默认也只监听 127.0.0.1:7865。保持此终端运行。

03 · 在本机终端建立 SSH 转发

ssh -N -L 7865:127.0.0.1:7865 user@server

将 user@server 换成你的服务器账号与地址，保持 SSH 连接。

然后在本机浏览器打开 http://127.0.0.1:7865。图片路径填写服务器上的目录；若就在本机运行，可直接打开该地址，无需 SSH 转发。

如何核对下载文件的 SHA-256？

下载同目录下的 SHA256SUMS，将输出的哈希与对应文件记录比较。Windows 在下载目录打开 PowerShell：

Get-FileHash .\webcompare-desktop-*-windows-x64.zip -Algorithm SHA256

Linux 在下载目录执行：

sha256sum --check SHA256SUMS --ignore-missing
WebCompare· 让每一处细节都有据可比。
